# 贺州学院校园网 / zaxsoft 校园网认证小工具（HZXYNET-AutoLogin）

贺州学院校园网（zaxsoft 石斧软件 portal）自动登录小工具：Rust + Win32 写的 Windows 单文件 exe，双击即用，不用装任何运行库。开机自动认证、掉线自动重连，新版 SPA 门户与旧版表单门户自动识别。账号限 1 电脑 + 1 手机同时在线，所以做了 PC / 手机双槽位。

> 同协议的路由器版：[PortalKeeper](https://github.com/d2su8/PortalKeeper)（OpenWrt 插件）。本项目由 AI 辅助完成，见 [AI-NOTES.md](AI-NOTES.md)。

## 功能

- 探测劫持 → 解析登录页 → 提交 → 复核放行，全自动；已在线只探测不重复登录
- PC / 手机双槽位（按 UA 切换），一键下线只踢自己，不自动顶号
- 双网卡机器可按网卡绑源 IP 发包
- 开机自启并自动认证：勾选后写注册表启动项，重启最小化启动，网络就绪即用已存凭据登录
- 掉线自动重连：后台定时探测，掉线立即重试，之后按间隔重试（间隔/次数可调，统计掉线与重连次数）
- 密码用 DPAPI 加密（绑定当前用户），存在 exe 同目录 `campus-auth.dat`，**别分享这个文件**
- 门户地址自动发现，新版 SPA 与旧版表单门户按登录页自动识别，换个同类型门户的学校不用改代码

## 使用

1. [Releases](../../releases) 下载 `campus-auth-1_4_0.exe`（版本号中的点写成下划线，随版本更新），双击
2. 选连接了校园网的网卡（10.200/10.202 段会自动识别）
3. 输账号密码，选电脑端 / 手机端，点「一键认证登录」
4. 认证成功后即可上网；可勾选「保存账号密码(加密存储在本地)」实现下次自动填充
5. 「自动认证」分组可选开机自启并自动认证、掉线自动重连（需先保存账号密码），重试间隔/次数可调
自己编译：`cargo build --release`，产物在 `target/release/campus-auth-1_4_0.exe`。

## 仓库结构

```text
src/
├─ main.rs       # Win32 原生 GUI（窗口/控件/消息循环 + 自动认证监控）
├─ lib.rs        # 共享引擎库
├─ auth.rs       # 认证引擎（探测/登录/复核）
├─ autostart.rs  # 开机自启（注册表 Run 项）
├─ selfsvc.rs    # 自助接口（在线设备/下线/清绑定）
├─ net.rs        # 网卡枚举 + 绑源 IP 的 HTTP 客户端
├─ crypto.rs     # DPAPI 加密
├─ store.rs      # 数据文件（配置 + 加密凭据 + 滚动日志）
└─ common.rs     # 常量与工具
docs/PROTOCOL.md # 认证协议文档
```

## 换学校

门户地址不写死：探测被 AC 302 劫持就跟跳转走，表单字段从登录页现解析。探测不到时，用浏览器打开任意 http 网站，把跳转后的认证页地址粘到「门户地址」框即可。
